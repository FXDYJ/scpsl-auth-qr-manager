# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

PHP with OpenSSL behind Nginx synchronizes the trusted public keys. A self-hosted browser worker decodes images and camera frames. Web Crypto verifies signatures locally, including offline.

## Users

SCP:SL administrators reviewing player authentication QR codes captured in evidence.

## Product Purpose

Import one or more screenshots, verify the decoded authentication records and make the signed fields easy to inspect. Keep past queries in the current browser automatically, with search, notes, re-verification and redacted export.

## Capabilities and Constraints

Separate signature authenticity from the game login validity window. Images and signed evidence stay in the browser. An installable offline application keeps the scanner and a root-verified key snapshot available after initial setup. Show the limits of the available trusted keys and the missing game connection context.
